01 / PRINCIPLES

Principles

A page shows the content people need to read and the actions they need to take. Color, spacing, and motion have fixed roles and do not change from page to page.

01

Content first

Numbers and useful information lead the eye. Decoration appears only when it carries meaning.

02

Consistent order

Use the same spacing, alignment, and grouping throughout. The same meaning always gets the same visual treatment.

03

Warm restraint

Soft sage green, generous corners, and plain language keep a precise data interface approachable.

Do

Build hierarchy with weight, size, and space.

Avoid

Neon colors, page gradients, glows, and decoration without a purpose.

02 / FOUNDATIONS

Foundations

A shared visual grammar keeps the experience consistent across platforms and screen sizes. Every foundation value comes from a semantic token.

02.1

Color

A black night theme and a warm paper theme share the same semantics. Changing the theme changes surfaces and contrast, not layout.

Narrow screens stay single column. Wide screens cap the reading width and center the content. Reflow multi-column controls before reducing type. Fixed actions must not cover inputs, and scrollable content leaves about 144px behind a floating navigation bar.

02.4

Shape & depth

Rounded corners are soft without becoming playful. Thin borders define surfaces; shadows only suggest a slight spatial relationship.

Do

Use a 1px translucent card border and 0.7px dividers.

Avoid

Outlining every nested element or stacking heavy shadows.

02.5

Motion

Motion confirms input and preserves spatial continuity. It is not a demonstration of technique. Nothing loops, and entrances do not queue.

PRESS170 msscale 0.97 · opacity 0.90
Selection240 ms
Segmented thumb300 ms
Page entrance440 ms

Respect the system “Reduce motion” setting. Replace spatial movement with an immediate state change or a quick fade.

03 / COMPONENTS

Components

A finite set of composable variants covers most product needs. Every specimen below is a real control and can be used directly.

03.1

For submitting, confirming, and navigating. One primary action per area; everything else is secondary, outline, quiet, or glass.

04.2

Accessibility

Accessibility is part of every component, not a separate review step.

01

Visible focus

Use a deep sage focus ring. Focus order follows reading order.

02

Enough contrast

Check text contrast on the actual composited surface, not on theoretical translucent values.

03

More than color

Pair color with text, shape, icons, and status wording.

04

User preferences

Support text scaling, reduced motion, keyboard input, and screen readers.
